## 统计说明

- DSH 卡片按“行业 + 能力种类”展开，因此同一项目可能出现在多个行业或种类中；总卡片数仍按唯一卡片 ID 计算。
- 新搜寻候选按本轮设计中的功能组分类；后续写入代码时仍会映射到 UI 的五种能力种类。
- 金融项目只作为资料、研究、回测或开发参考；科研写作项目只辅助用户自己的研究材料，不承诺直接生成可提交论文。
- GitHub Star 由 agent-reach 使用 GitHub CLI 快照读取，不做运行时联网刷新。
