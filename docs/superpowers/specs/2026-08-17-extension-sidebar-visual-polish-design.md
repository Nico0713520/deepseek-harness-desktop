# 扩展入口侧栏美化设计

## 目标

让“扩展中心”和“我的扩展”看起来像 DeepSeek Harness 官方侧栏原生功能，而不是后加的临时按钮。入口位置、路由和功能保持不变。

## 视觉基线

- 以运行中的官方“新会话”按钮为唯一基线：252×38px、12px 圆角、1px 中性边框、14px/22px/500 字体。
- 默认使用白色背景和主文字色；悬停、当前页和键盘焦点只使用官方中性浅灰，不使用蓝色描边或渐变。
- 图标与文字间距为 6px，与“新会话”一致。
- 两个入口保持 4px 垂直间距，并与“新会话”保留 8px 分组间距。

## 图标

- 不再使用字体字符 `✦` 和 `◈`，避免字体平台差异和临时感。
- “扩展中心”使用 16px 单色线性“模块中心”SVG。
- “我的扩展”使用 16px 单色线性“扩展收纳”SVG。
- 两个 SVG 均使用 `currentColor`、1.5px 描边、圆角端点，并标记为装饰性图标。

## 交互与无障碍

- 当前路由继续通过 `aria-current="page"` 表达。
- 键盘焦点保留低对比度中性焦点环；鼠标点击后不出现突兀蓝框。
- 折叠侧栏时只显示图标，按钮仍保留完整 `aria-label`。

## 验收

- 三个按钮的 x、宽度、高度、圆角、边框、字号和内边距一致。
- 图标尺寸、描边和文字基线一致，无字体字符图标。
- 扩展中心与我的扩展路由、折叠侧栏行为和现有测试保持正常。
