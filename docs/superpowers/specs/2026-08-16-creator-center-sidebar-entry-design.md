# 能力中心侧栏一级入口设计

## 背景

当前能力中心只注册在设置弹窗中，面积小、入口隐蔽，也无法形成类似 Codex 插件页或 WorkBuddy 专家页的“独立工作区”体验。本次改动把能力中心提升为 DeepSeek Harness 左侧栏的一级入口，位置放在“新会话”下方、工作区和对话列表上方；点击后，右侧主区域显示完整能力中心页面。

## 目标

- 让小白能在左侧一眼找到“能力中心”，知道这里可以给 Harness 增加能力。
- 复用现有能力中心内容模型与视觉设计，把它从设置卡片扩展为完整主页面。
- 保留官方会话列表、工作区、设置和聊天流程，不改动会话数据及消息链路。
- 让“能力中心 ↔ 聊天”切换简单：点击入口进入，点击新会话或历史对话返回。
- 把官方更新影响控制在一个明确、很小的侧栏兼容层内。

## 非目标

- 本轮不开发新的能力库内容、真实安装器或远程插件市场。
- 本轮不重写官方会话列表、ConversationRoot 或整个 AppFrame。
- 本轮不把能力中心做成独立窗口或新后端服务。

## 用户体验

### 左侧栏

新增一级入口：`能力中心`。入口位于：

```text
DeepSeek Harness
新会话
能力中心       ← 新增
工作区
  对话任务...
设置
```

入口采用官方侧栏行的尺寸、字体、悬停和选中态；图标使用与扩展/能力相关的简洁线性图标。选中能力中心时，左侧栏保持可见，入口显示选中态。

设置页不再承载完整能力中心页面，避免出现两个入口。若需要兼容旧路径，可以保留一个很小的“打开能力中心”跳转项，但不再嵌入旧的窄卡片。

### 主区域

能力中心占用右侧主区域的完整宽度，使用独立滚动容器，不遮挡左侧栏。页面沿用当前能力中心的内容数据，但重新使用完整页面布局：

1. 页面标题：“能力中心”
2. 说明：“先说你想解决的问题，再挑一个适合你的能力。”
3. 顶部导航：`能力库`、`Vibe Coding`、`扩展教程`
4. 首屏问题入口：输入“我希望 DeepSeek 帮我解决什么问题”，并提供“让 AI 帮我选”按钮
5. 精选场景横向卡片
6. 两组分开的筛选：行业分类、能力类型
7. 三列能力卡片；点击卡片进入详情/创建流程

能力中心打开时关闭详情栏，避免主区域被挤窄。点击“新会话”、工作区或任一历史对话后退出能力中心并恢复官方聊天页面。能力中心本身不改变当前会话消息。

## 技术方案

### 侧栏接入

当前官方 `ui-sidebar` 只暴露 `sidebar.workspaces`、`sidebar.settings` 和 `sidebar.footer.action`，没有“新会话下方”的细粒度插槽。因此增加一个最小兼容插槽：

```text
sidebar.primary.action  (list, root scope)
```

官方侧栏壳只负责在新会话按钮后渲染这个列表；能力中心插件负责注册自己的行。除声明插槽和渲染位置外，不复制或重写工作区/会话列表。

这层补丁必须保持为独立、可定位的上游兼容变更；官方侧栏版本升级时，只需要检查该插槽是否仍存在，补丁冲突应在构建阶段暴露。

### 主区域接入

能力中心使用官方 `shell.overlay` 列表插槽作为全框架浮层。插件通过现有侧栏宽度和布局状态，把浮层对齐到主内容区左边界，并在进入能力中心时关闭详情栏。浮层仅覆盖主区域，侧栏保留可交互状态；退出时卸载浮层，不修改官方 ConversationRoot。

能力中心入口与主区域通过插件内部的轻量状态控制器通信。状态只表示 `chat` 或 `creator-center`，不写入会话记录；页面刷新默认回到聊天页。

### 现有功能复用

- 复用现有 `CreatorCenter` 的能力库、行业/类型分类、Vibe Coding、教程和 SessionLauncher。
- 把原来设置页专用的容器样式拆成全页面容器样式。
- 保留现有 API 和能力库数据结构，未来新增库内容只需补充数据条目。
- 保留鲸鱼主题和桌宠的 `shell.overlay` 注册，确保两个浮层互不覆盖关键交互；能力中心打开时桌宠可以继续显示在右下角。

## 稳定性与更新策略

- 不修改消息、会话、工作区和模型请求逻辑。
- 入口使用明确的 slot contract，不依赖文本查找或脆弱的 DOM 注入。
- 侧栏兼容层增加 slot contract 测试，验证入口顺序为 New Session → Ability Center → Workspaces。
- 主区域增加打开、退出、详情栏关闭、侧栏折叠和窗口缩放测试。
- 打包 smoke test 验证插件未加载时官方 UI 仍可正常启动，插件加载时能力中心能打开。

## 验收标准

- 左栏“能力中心”出现在新会话下方、工作区上方。
- 点击入口后，右侧出现完整宽度能力中心，不再是设置弹窗中的小卡片。
- 点击新会话、工作区或历史对话后，能回到正常聊天界面。
- 能力中心中的搜索、行业/类型筛选、Vibe Coding、教程和已有创建流程继续可用。
- 左侧栏折叠、展开、窗口缩放后，入口和主区域仍可用。
- 官方聊天消息、会话列表、工作区和鲸鱼主题/桌宠不受影响。
- 类型检查、单元测试、构建和本地打包 smoke test 全部通过。
