# 能力详情页舒适排版设计

## 问题

详情内容精简后仍沿用满宽、贴顶和外层大边框布局，导致内容挤在左上方，页面下半部出现被边框圈住的大面积空白。

## 方案

- 详情模式隐藏能力库的外层边框和背景，只保留真正承载内容的详情卡。
- 详情卡最大宽度 900px，水平居中。
- 顶部使用 `clamp(36px, 8vh, 84px)` 响应式留白；宽屏不贴顶，小窗口不会浪费过多空间。
- 详情卡使用中性边框和轻阴影，避免嵌套蓝色边框造成视觉噪音。
- 返回、标题、项目简介、仓库、操作和高级信息保持原有阅读顺序，不恢复已删除内容。
- 760px 以下恢复满宽，顶部留白缩小到 18px，操作按钮继续纵向排列。

## 验收

- 列表模式仍显示能力库外层容器。
- 详情模式能通过稳定属性识别，外层无大边框，详情卡居中且宽度不超过 900px。
- 详情内容、按钮、返回、Escape 和高级信息交互不变。
