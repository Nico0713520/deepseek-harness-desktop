# Creator Center Sidebar Entry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将能力中心从设置弹窗提升为左侧“新会话”下方的一级入口，并在右侧主区域提供完整、可返回聊天的能力中心页面。

**Architecture:** 给官方 dsh-client-ui-sidebar 增加一个可审计的 sidebar.primary.action 插槽补丁，只在“新会话”后渲染能力中心入口。能力中心插件通过官方 shell.overlay 插槽覆盖主区域，不替换 ConversationRoot、不改变会话数据；一个轻量导航控制器负责入口、返回和会话切换状态。

**Tech Stack:** React 18, TypeScript 6, CSS Modules, DeepSeek Harness Cordis slots, pnpm package patch, Vitest, Testing Library.

## Global Constraints

- 左栏入口必须位于“新会话”下方、工作区和对话列表上方。
- 本轮不开发新的能力库内容、真实安装器或远程插件市场。
- 本轮不重写官方会话列表、ConversationRoot 或整个 AppFrame。
- 不修改消息、会话、工作区和模型请求逻辑。
- 入口使用明确的 slot contract，不依赖文本查找或脆弱的 DOM 注入。
- 页面刷新默认回到聊天页；能力中心状态不写入会话记录。
- 必须通过类型检查、单元测试、构建和本地打包 smoke test。
