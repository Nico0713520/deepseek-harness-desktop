安装社区插件

确认仓库、许可证和 DSH 兼容版本后，在终端运行：

dsh plugin --profile web add <package>

安装后重启 Harness。卸载前先备份工作区和 profile 配置。

安全原则：只对内置或明确验证过的扩展提供自动安装；来源不明的包只展示链接和教程。
